# 👋 Bonjour, je suis BBR Maker

Passionné d’**avancée numérique** depuis une dizaine d’années, j’explore et je bidouille tout ce qui touche à l’**impression 3D**, aux **drones** et à la **personnalisation de machines**.

Ici, je partage :
- mes **meilleures configurations** (firmware, slicers, profils d’impression, réglages drones, etc.)
- mes **personnalisations** pour différentes machines et plateformes
- des projets concrets pour **avancer dans le bon sens du futur** 🚀

## 🖨️ Impression 3D

Ce que vous trouverez dans ce profil autour de l’impression 3D :

- **Profils d’impression** :  
  - PLA, PETG, ABS, ASA, TPU, composites  
  - Configurations par machine et par trancheur (PrusaSlicer, OrcaSlicer, Cura, etc.)
- **Améliorations hardware** :  
  - Mods de hotend, ventilation, rigidité, capteurs  
  - Pièces techniques imprimées pour renforcer ou adapter des machines
- **Firmware & calibration** :  
  - Marlin / Klipper : configs, macros, scripts de calibration  
  - Nivellement, pressure advance, input shaping, etc.


## 📦 Dans ce profil

Vous trouverez des dépôts avec :

- des **profils d’impression** et configurations prêtes à l’emploi  
- des **firmwares / configs** pour drones et autres machines  
- des **outils et scripts** pour automatiser et améliorer vos setups  

Chaque dépôt contient, quand c’est pertinent :

- une description claire de l’usage  
- les machines / matériaux / firmware concernés  
- les réglages de base et les variantes testées  

## 🤝 Contribuer / échanger
